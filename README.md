# TrueHome Kenya (makaokenya)

TrueHome Kenya is a modern real estate platform designed to connect property seekers with verified landlords and trusted agents across Kenya.

## Features

- **Property Search & Browsing**: Easily search and filter property listings by type, price, location, and amenities on `index.html`.
- **Property Listing (`list.html`)**: Landlords and agents can list properties by entering comprehensive details including title, type, price, location, bedrooms, bathrooms, description, and contact info.
- **Verified Landlord Badge**: Uploading National ID and Title Deed / Land Registry documents automatically issues the **Verified Landlord** badge to enhance trust and listing visibility.
- **Instant Rendering**: Property listings submitted via `list.html` are saved locally to `localStorage` for instant rendering on `index.html`.
- **Consistent TrueHome Kenya Branding**: Unified design, modern Tailwind CSS UI, and consistent branding across all pages.

## Getting Started

1. Open `index.html` in your web browser to browse available properties.
2. Navigate to `list.html` to post a new listing with document uploads for verification.
